A small Go server takes the webhook and runs your checks on the changed lines. An agent reviews the diff in a checkout of the PR, and a second model checks every finding against the code before anything is posted.

<CardGrid>
	<Card title="Verified findings">A second model checks every finding against the code and drops what it can't back up.</Card>
	<Card title="Your own checks">tsc, eslint, biome, golangci-lint, gitleaks, osv-scanner, your tests [and more](how-it-works/#checks), on the changed lines.</Card>
	<Card title="Incremental">A push reviews only what changed. A rebase reviews nothing.</Card>
	<Card title="Committable fixes">Fixes come as suggestion blocks you can commit from the PR. Fixed threads get resolved.</Card>
	<Card title="Learnings">Tell the bot once, and the next reviews follow the rule.</Card>
	<Card title="Any model">OpenAI, Anthropic, DeepSeek, Bedrock, Azure OpenAI or your own gateway, with fallback to a second provider.</Card>
	<Card title="PR reports">An optional HTML page per PR: reading order, diffs with findings, call graphs, merge risks.</Card>
	<Card title="Self-hosted">One container, Go standard library only. Your code stays on your server and with your model provider.</Card>
</CardGrid>
